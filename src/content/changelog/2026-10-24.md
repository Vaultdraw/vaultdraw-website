These changes are done in the app but not in a release yet. They are not in 0.1.2, and this list grows until the next version ships.

### New

- **Key sequences and which-key.** A key in `[hotkeys]` can be several chords, such as `"g g"` or `"<leader> f f"`, with a leader key (default `Backslash`). A popup lists what can follow a half-typed sequence. Nothing is bound by default, and nothing loads until you write a sequence. The tool keys (`R`, `E`, `A` and the rest) are now commands (`tool.rectangle`, `tool.eraser`, …) with the same default keys, so they can be rebound too. See [Keyboard](/docs/keyboard/#key-sequences-leader-and-which-key).
- **Key group names.** **Settings → Hotkeys → Key group names** names a group of sequences, which the which-key popup shows. It writes `[keys.labels]` for you and keeps your comments.
- **`vaultdraw://` links.** Open a drawing or vault, start a search, create a drawing or run a palette command from a note, a web page or a script. Opening and searching run at once. Switching vault, creating a drawing and running a command ask first. `vaultdraw uri <url>` does the same from Terminal. `control.uri_enabled = false` turns links off. See [Links and files from outside](/docs/links-from-outside/).
- **Open With Vaultdraw.** Finder lists Vaultdraw for `.excalidraw` drawings and `.excalidrawlib` libraries (your default app is not changed). A file outside every vault asks: copy it into the vault, open its folder as a vault, or cancel. On Linux, the palette command **Links: Register Vaultdraw for links and files (Linux)** sets it up; it has not been tried on a Linux desktop yet.
- **`vaultdraw export`.** Renders a drawing to PNG, SVG or PDF through the running app, to a file, a folder or stdout, and never replaces a file unless you pass `--force`. A folder exports with `--out-dir`, one frame with `--frame`. See [Control the app](/docs/cli-app/#export-a-drawing).
- **File tree and list keys.** `j`/`k` move, `h`/`l` close and open folders, Enter opens, `r` renames, `a` creates, `d` deletes, `m` moves, **Cmd+Option+F** focuses the tree. The Tags list, Links panel and Settings list use the same `list.*` commands, which can be rebound. See [Keyboard](/docs/keyboard/#file-tree-and-list-keys).
- **Gallery and graph keys are commands.** `gallery.*` and `graph.*` can be rebound in `[hotkeys]`. `graph.fit` now has the default key `0`. See [Keyboard](/docs/keyboard/#gallery-and-graph-keys).

### Faster

- **Memory comes back after you delete images.** Image data that no undo or redo step can restore is freed about 20 seconds after you stop editing. Saved drawings do not change. New keys: `memory.free_unused_images` (default on) and `memory.undo_steps` (default 1000; undo was unlimited before). See [Settings](/docs/settings/#memory).
- **Faster first search.** `vaultdraw search` and the first in-app search on a vault with no index take about 240 ms instead of 360 ms on 5,000 drawings, with 20 to 30 percent less CPU. See [Search](/docs/search/#the-search-index).
- **Thumbnails for bigger drawings.** `interface.thumbnail_max_elements` (default 8000, was a fixed 2,500, range 100 to 50000) sets the biggest drawing that gets a thumbnail. It applies live. See [Configuration](/docs/configuration/).
