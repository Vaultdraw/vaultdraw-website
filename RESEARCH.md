# Research: reference sites

Looked at on 2026-10-22, to borrow a feel, not code, text or assets.

## cendretheme.com (the main reference)

- **One long page, editorial.** A sticky hairline header; numbered sections separated by thin rules; a 1180 px column with generous space. Each section is a small uppercase label, one paragraph, and one strong visual.
- **Type does the work.** Serif body (Charter-like, 17 px / 1.6) for reading, monospace for everything structural: labels with very wide tracking (≈0.28em), tabs, captions, numbers. The wordmark is a huge monospace word with one accent-coloured half.
- **The product is the visual.** Code panels with file tabs, line numbers and real syntax colours; an editor mock with diagnostics and a status line; palette cards with a colour bar on top. No stock imagery, no gradients, no icons for decoration.
- **Theme as interaction.** A segmented control in the header (hard / medium / soft) re-measures the whole page live. A thin accent line under the header tracks scroll progress.
- **Tone.** Short, specific, slightly wry sentences with real numbers. It argues rather than sells.

## noctalia.dev

- A more conventional product site: centred hero with logo, headline with one coloured word, primary + ghost buttons, a network-of-dots background, feature cards below.
- Useful bits: the palette format (Vaultdraw's themes use it), the dark-first look, and a "Palettes" page that treats themes as a first-class feature.
- Less useful: centred marketing hero and animated background feel generic next to Cendre.

## What this site takes from them

| Idea | From | Here |
| --- | --- | --- |
| Serif body, mono structure, wide-tracked labels | Cendre | Newsreader + JetBrains Mono |
| Numbered sections with hairlines | Cendre | 01–07 on the home page |
| Product as the visual | both | Real screenshots from the app, a real Excalidraw sketch |
| Live theme switch in the header | Cendre | The app's own themes re-dress the page and swap the screenshots |
| Palette cards with a colour bar | Cendre | Feature cards using the theme's ANSI colours |
| Themes as a feature | Noctalia | A grid of all built-in palettes |

What makes it Vaultdraw's own rather than a Cendre copy: the hand-drawn layer (Excalifont wordmark, margin notes with drawn arrows, an SVG drawn in Excalidraw itself), and a site that literally wears the product's themes.
