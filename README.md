# Vaultdraw website

Marketing site, docs and changelog for [Vaultdraw](https://github.com/Vaultdraw/vaultdraw), an offline vault for Excalidraw drawings.

It's a static [Astro](https://astro.build) site: plain HTML and CSS, about 6 kB of JavaScript, no trackers and no third-party requests.

## Quick start

Requires Node 18 or newer.

```sh
npm install
npm run dev        # http://localhost:4321
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server with live reload |
| `npm run build` | Static site in `dist/` |
| `npm run preview` | Serve `dist/` locally, as it will be deployed |
| `npm run themes` | Copy the app's built-in themes into `src/data/themes.json` |
| `npm run shots` | Re-take the app screenshots and the hero sketch |

## Where things live

| What | Where |
| --- | --- |
| Home page | `src/pages/index.astro` |
| Docs | `src/content/docs/*.md` (`order` in the front matter sets the sidebar order) |
| Changelog | `src/content/changelog/*.md`, one file per entry |
| Download page | `src/pages/download.astro` |
| Themes | `src/data/themes.json` (generated, do not edit) |
| Screenshots | `src/assets/shots/` (generated by `npm run shots`) |
| Hero sketch | `src/assets/sketches/` (exported from the app) |
| Styles | `src/styles/` |
| Theme and motion scripts | `src/scripts/` |

## Screenshots and themes come from the app

The site doesn't use mockups. Both come from the app's own UI:

- `npm run themes` reads the built-in themes from the app repo.
- `npm run shots` builds the app's Playwright harness, seeds it with the sample vault in `scripts/capture/vault.mjs`, and photographs each screen in every featured theme, in light and dark.

Both scripts read the app checkout at `../vaultdraw`. Set `APP_DIR` to use a different path:

```sh
APP_DIR=~/code/vaultdraw npm run themes
```

To re-take only some shots, use `--only`, `--theme`, `--mode` or `--sketches`. The screens are defined in `scripts/capture/screens.mjs` and the featured themes in `src/data/featured.mjs`.

## Deployment

The site is deployed to Cloudflare Workers from the `main` branch. Each push rebuilds it.

- `wrangler.jsonc` serves the built `dist/` folder.
- `public/_headers` sets the security headers and caching rules.
- Set `SITE_URL` to the public address when deploying, so the canonical links and social preview point at the right place. It defaults to `http://localhost:4321`.

## Design notes

- **Private by default.** Fonts are self-hosted, there are no cookies or analytics, and the content security policy only allows the site's own origin.
- **Fast.** Screenshots ship as AVIF and WebP at several sizes. Motion is CSS, plus one small script for the hero sketch. Everything is skipped for visitors who prefer reduced motion.
- **Accessible.** Semantic HTML, keyboard navigation with visible focus, and colours checked for contrast against each theme.
